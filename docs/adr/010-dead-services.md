# ADR 010: Dead services are not ported

Status: accepted (2026-11-07)

**Decision.** Hosts that have shut down (Copy, Drop.io, FileSonic, Photobucket API, ImageShack API, Hostr, StumbleUpon, Delicious, Firebase Dynamic Links, Immio) are not ported. Parity in FEATURES.md is counted against live services. The list is re-checked when M7 starts.
