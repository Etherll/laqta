# ADR 010: Dead services are not included

Status: accepted (2026-11-07)

**Decision.** Hosts that have shut down (Copy, Drop.io, FileSonic, Photobucket API, ImageShack API, Hostr, StumbleUpon, Delicious, Firebase Dynamic Links, Immio) are not included. Feature coverage in FEATURES.md counts only live services. The list is re-checked when M7 starts.
